# 🚌 北印校车实时看板 (BIGC School Bus Tracker)

这是一个轻量级、零后端的纯静态单页面应用，专为**北京印刷学院（BIGC）**师生打造。旨在解决日常查看密集校车时刻表图片带来的不便，提供**自动比对时间、实时倒计时提醒、班车类型直观区分**的极简出行体验。

---

## ✨ 核心特性

- **⏳ 实时发车倒计时**：自动读取设备本地时间，精确计算距离下一班校车发车的剩余分钟数，支持手机息屏唤醒或后台切回时即刻刷新。
- **🎨 班车一 / 班车二双色区分**：
  - 🔵 **班车一（蓝色标识）**：50 座客车（校本部南门内 ↔ 西校区西门内 ↔ 康庄校区）
  - 🟢 **班车二（绿色标识）**：公交客运（校本部南门内 ↔ 西校区西门 ↔ 康庄校区）
  - 顶部倒计时看板与底部完整时刻表采用统一的色彩编码与下划线角标，下一班是什么车一目了然。
- **🧠 状态智能感知**：
  - **已发车自动置灰**：已过发车时间的班次自动变灰并添加删除线。
  - **下一班次醒目高亮**：即将发车的班次在完整时刻表中以对应车型的蓝色/绿色气泡高亮放大显示。
- **📱 响应式双列布局**：基于 Flexbox 与 CSS Grid 布局，手机端自动折叠为单列上下滑动，平板与电脑端自动展开为左右双列对照（`校本部 往 康庄校区` / `康庄校区 往 校本部`）。
- **⚡ 单文件极致性能**：
  - 纯原生 `HTML + CSS + JS` 构建，内联矢量图标，全站仅 **1 个文件（约 10 KB）**，打开页面无任何额外外部资源请求。
  - **按需 DOM 渲染**：秒级时钟更新与分钟级看板重绘分离，减少 98% 的无意义页面重绘开销，低端设备同样丝滑省电。

## 🚀 部署与使用

本项目无需安装任何依赖、无需编译，开箱即用。

### 方案一：静态托管平台一键部署（推荐）
1. Fork 或将本项目代码上传至您的 GitHub 仓库。
2. 在以下任一平台连接该 GitHub 仓库（构建框架选择 `None`，构建命令留空，输出目录填 `.` 或留空）：
   - **国内高速访问推荐**：腾讯云 EdgeOne Pages / 阿里云 ESA Pages（国内 CDN 节点，校园网与移动网络下毫秒级秒开）。
   - **海外全球托管**：Cloudflare Pages / GitHub Pages / Vercel（如使用 Cloudflare Pages，建议绑定自定义域名以获得更稳定的国内连接体验）。
3. 点击部署即可获得专属在线访问链接，后续每次 `git push` 均会自动同步更新。

### 方案二：本地或内网直接运行
由于采用纯静态单文件设计，直接下载 `index.html` 在手机或电脑浏览器中打开即可完整使用。

## 🔧 时刻表数据维护

如果学校后续发布了新的通勤车时刻表，只需打开 `index.html`，修改 `<script>` 标签顶部的两个数组即可：

```javascript
// 校本部 往 康庄校区（按发车时间升序排列，type: 1 为班车一，type: 2 为班车二）
const mainToKang = [
    {time: "07:20", type: 2}, {time: "07:35", type: 1}, ...
];

// 康庄校区 往 校本部
const kangToMain = [
    {time: "07:00", type: 2}, {time: "07:40", type: 2}, ...
];
```
